# achievements

本仓库用于点亮 GitHub 个人主页成就徽章（Achievements）。等级门槛来自 GitHub 官方社区讨论 #209029。

## 最终进度（2026-10-07，全部可自助成就已达最高等级）

| 成就 | 等级门槛 | 进度 |
|------|----------|------|
| Quickdraw | 5 分钟内关闭 issue / PR（无等级） | ✅ 已点亮 |
| Yolo | 合并无评审 PR（无等级） | ✅ 条件已满足 |
| Pull Shark | 2 / 16 / 128 / 1024 个合并 PR | ✅ **1080 个 → 金级** |
| Galaxy Brain | 2 / 8 / 16 / 32 个采纳答案 | ✅ **34 个 → 金级** |
| Pair Extraordinaire | 1 / 10 / 24 / 48 个联合署名合并 | ✅ **49 个 → 金级** |

## 实现方式

- **Quickdraw**：issue #1 开启 3 秒后关闭
- **Yolo**：PR #2 无评审直接合并
- **Pull Shark**：`notes/` 里程碑 PR squash 合并
- **Galaxy Brain**：Q&A 分类 Discussions 自问自答并采纳
- **Pair Extraordinaire**：提交携带 `Co-authored-by` trailer 合并（历史 xinyu#4 与 @claude 署名首次解锁；`pair-notes/` 为后续 48 个金级里程碑）
